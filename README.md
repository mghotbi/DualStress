# DualStress (biotic + abiotic stressors)

Cross-domain integration and redox-active microbial taxa: DIABLO-based multi-omics integration revealed block-specific cross-domain correlations linking microbial, soil, plant, and VOC profiles (Fig 4). Notably, the abundance of an Anaeromyxobacter amplicon sequence variant (ASV) correlated positively with Fe²⁺ and Mn²⁺ concentrations, suggesting a role in metal- and nitrogen-coupled redox cycling. Anaeromyxobacter functions as a biogeochemical redox stabilizer, oxidizing root-derived carbon while reducing metals and nitrate, thereby lowering local redox potential 99. Such activity likely dampens ROS/RNS accumulation and indirectly protects roots from oxidative injury, an emergent example of microbiome-mediated redox buffering.
