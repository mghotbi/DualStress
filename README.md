### 🌱 ROS/RNS Phenotyping for Maize Holobiont Resistance  
To profile oxidative resilience in maize root tips, we use **high-throughput fluorescence microplate assays**—including [CellROX Green/Deep Red and CM-H DCFDA](https://www.thermofisher.com/de/de/home/life-science/cell-analysis/cell-viability-and-regulation/oxidative-stress.html) for reactive oxygen species and **DAF-FM** for nitric-oxide detection.  
These plate-reader methods deliver rapid, sensitive redox measurements, enabling genotype- and microbiome-level screening of maize holobionts under combined flooding × herbivory stress.
